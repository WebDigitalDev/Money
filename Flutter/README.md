# Money

Aplicação híbrida de gestão de empréstimos pessoais desenvolvida em Flutter.

O Money utiliza português do Brasil e o Real brasileiro (BRL) como padrões
definitivos para textos, datas, valores, carteiras, transações e metas.

## Desenvolvimento

O projeto requer Flutter 3.44.9 ou superior e Dart 3.12.2 ou superior.
